🎯 เรียนจบแล้ว หนูจะ…

  • จำคำที่ใช้ ใ ไม้ม้วน 20 คำ ได้ และเลือก ใ / ไ ได้ถูก
  • ใช้ ไม้ยมก ( ๆ ) และ ไปยาลน้อย ( ฯ ) ได้ถูกต้อง
  • อ่านคำที่มี ฤ เช่น ฤดู ฤทธิ์ อังกฤษ ได้

🔊เปิดเสียงก่อนเรียนนะ

บทเรียนนี้ อ่านออกเสียง ให้ฟัง แตะปุ่มเพื่อลองฟัง แล้วเลือกความเร็วที่เด็กฟังทัน

ความเร็วเสียงอ่าน:

💡 ถ้าไม่มีเสียง ให้เปิดเสียงเครื่องและปิดโหมดเงียบ แล้วแตะใหม่อีกครั้ง

🌀คำที่ใช้ ใ ไม้ม้วน มีแค่ 20 คำ · แตะเพื่อฟัง

เคล็ดลับครูอู๋: จำ 20 คำนี้ให้ได้ คำไทยอื่น ๆ ที่ออกเสียง "ไอ" ใช้ ไ ไม้มลาย เกือบทั้งหมด เช่น ไก่ ไข่ ไฟ ไม้

📜กลอนช่วยจำ ใ ไม้ม้วน 20 คำ · แตะทีละบรรทัดเพื่อฟัง

🔁ไม้ยมก ( ๆ ) · ใช้เมื่อพูดคำเดิมซ้ำ

ไม้ยมก ( ๆ ) ใช้เขียนแทนคำเดิมที่ต้องอ่านซ้ำ 2 ครั้ง และควรเว้นวรรคหน้าและหลัง ๆ

✅ เด็ก ๆ เล่นกัน · เดิน ช้า ๆ

❌ ไม่ใช้ ๆ เมื่อเป็นคนละคำ เช่น "นาๆ ชนิด" ควรเขียน นานาชนิด

✂️ไปยาลน้อย ( ฯ ) และไปยาลใหญ่ ( ฯลฯ )

ไปยาลน้อย ( ฯ ) ใช้ย่อคำยาวที่รู้กันทั่วไป แต่เวลาอ่านต้องอ่านเต็ม

ไปยาลใหญ่ ( ฯลฯ ) ใช้เมื่อยังมีอีกหลายอย่างที่ไม่ได้เขียน อ่านว่า "และอื่น ๆ" เช่น ผลไม้ไทย มีมะม่วง มังคุด ทุเรียน ฯลฯ
