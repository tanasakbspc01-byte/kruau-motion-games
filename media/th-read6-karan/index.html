ตัวการันต์และคำที่ใช้ รร

🎯 เรียนจบแล้ว หนูจะ…

  • รู้ว่า ตัวการันต์ ( ์ ) ทำให้ตัวอักษร ไม่ออกเสียง
  • อ่านคำที่มีตัวการันต์ เช่น การ์ตูน จันทร์ รถยนต์ ได้
  • อ่านคำที่ใช้ รร (ร หัน) เช่น กรรไกร ธรรม ได้ถูกต้อง
  • เขียน คำเหล่านี้ได้ไม่ตกตัวการันต์

🔊เปิดเสียงก่อนเรียนนะ

บทเรียนนี้ อ่านออกเสียง ให้ฟัง แตะปุ่มเพื่อลองฟัง แล้วเลือกความเร็วที่เด็กฟังทัน

ความเร็วเสียงอ่าน:

💡 ถ้าไม่มีเสียง ให้เปิดเสียงเครื่องและปิดโหมดเงียบ แล้วแตะใหม่อีกครั้ง

🤐ตัวการันต์คืออะไร

เครื่องหมาย ◌์ เรียกว่า ไม้ทัณฑฆาต วางบนตัวอักษรตัวใด ตัวนั้นเรียกว่า ตัวการันต์ และ ไม่ต้องออกเสียง

เคล็ดลับครูอู๋: ตัวการันต์ อ่านไม่ออกเสียง แต่ต้องเขียนเสมอ ถ้าลืมเขียน คำจะผิดทันที เช่น "รถยนต" ❌

🔁คำที่ใช้ รร (ร หัน) แบบที่ 1 · ไม่มีตัวสะกดตาม → อ่านว่า "อัน"

🔁คำที่ใช้ รร แบบที่ 2 · มีตัวสะกดตาม → อ่านเสียง "อะ" + ตัวสะกด

รร ทำหน้าที่เหมือน สระอะ แล้วใช้ตัวที่ตามมาเป็นตัวสะกด

🤐 ตัวการันต์

ตัวที่มี ์ ไม่ออกเสียง เช่น การ์ตูน = กา-ตูน, จันทร์ = จัน

🔁 รร ไม่มีตัวสะกด

อ่านว่า อัน เช่น กรรไกร = กัน-ไกร

🔁 รร มีตัวสะกด

อ่านเสียง อะ + ตัวสะกด เช่น ธรรม = ทำ, พรรค = พัก

✍️ เวลาเขียน

เขียน ตัวการันต์ และ รร ให้ครบเสมอ

ขั้นต่อไป: คำที่มักเขียนผิด (ใ ไม้ม้วน ฤ ๆ ฯ)
