# 🐱 KruAu ขยับกายได้ความรู้

เกมคณิตศาสตร์ ป.4–6 ที่เล่นด้วยการขยับร่างกายผ่านกล้อง และการเอียง iPad/โทรศัพท์ ใช้คู่กับเว็บ KruAu ห้องเรียนแสนสนุก

## เกมที่มี
| เกม | ชั้น / บท | วิธีเล่น | ลิงก์ (หลังเปิด Pages) |
|---|---|---|---|
| 🫧 ตบฟองคำตอบ | ป.4 บทที่ 4 การบวก ลบ คูณ หารระคน | กล้องจับมือ แตะฟองคำตอบ | `/p4-bubbles-cam/` |
| 🏃 วิ่งเก็บคำตอบทศนิยม | ป.5 บทที่ 2 ทศนิยม | เอียงเครื่องบังคับนักวิ่ง | `/p5-runner-tilt/` |

หน้ารวมเกม: `https://tanasakbspc01-byte.github.io/kruau-motion-games/`

## ➕ เพิ่มเกมใหม่ (สำหรับคุณครู)
1. สร้างเกมในแชท Claude ตามปกติ → แชร์ลิงก์สาธารณะ → วางลิงก์ claude.ai ในหลังบ้าน KruAu ได้เลย (ทีละหลายเกมก็ได้)
2. เปิด Claude Code ที่เชื่อม repo นี้ แล้วพิมพ์แค่ **"อัปเดตเกม"**
3. Claude จะอ่านชีตเอง ย้ายเกมที่ยังไม่ได้ย้ายมาไว้ที่นี่ และเพิ่มชื่อใน `games.json`
4. รอ 1–3 นาที เกมจะเปิดในเว็บ KruAu ได้เอง **ไม่ต้องแก้ลิงก์ ไม่ต้องวางโค้ด**

`games.json` = สมุดรายชื่อเกม (รหัสลิงก์ claude.ai → โฟลเดอร์เกม) เว็บ KruAu อ่านไฟล์นี้ตอนนักเรียนเปิดเกม

## เปิดใช้ GitHub Pages (ทำครั้งเดียว)
1. ใน repo นี้ กด **Settings** → เมนูซ้าย **Pages**
2. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch**
3. Branch เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอ 1–3 นาที แล้วรีเฟรชหน้า Pages จะเห็นลิงก์เว็บ

## นำไปใส่ในเว็บ KruAu
หลังบ้านคุณครู → **เพิ่มสื่อใหม่** → ประเภท **เกม** → วางลิงก์ของแต่ละเกม
เกมกล้องและเกมเอียงเครื่องควรเปิดในแท็บใหม่ เพราะเบราว์เซอร์มักไม่ให้ใช้กล้องและเซนเซอร์ในหน้าที่ฝังซ้อน

## โครงสร้างไฟล์
- `index.html` หน้ารวมเกม
- `lib/kit.js`, `lib/kit.css` หน้าเริ่ม ชื่อผู้เล่น ตารางคะแนน (เก็บในเครื่อง)
- `lib/motion.js` ตัวช่วยกล้องและการเอียงเครื่อง
- `lib/mediapipe/` ไลบรารี MediaPipe Tasks Vision 0.10.14 (Apache-2.0) สำหรับจับท่าทางในเครื่อง โมเดลโหลดจากเซิร์ฟเวอร์ของ Google ตอนเปิดเกมครั้งแรก
