# kruau-motion-games — กติกาสำหรับ Claude

repo นี้เก็บเกมของเว็บ KruAu (GitHub Pages: https://tanasakbspc01-byte.github.io/kruau-motion-games/)
เว็บ KruAu อ่าน `games.json` เพื่อเปลี่ยนลิงก์ claude.ai เป็นเกมใน repo นี้อัตโนมัติ (claude.ai เปิดซ้อนในเว็บอื่นไม่ได้)

## เมื่อผู้ใช้พิมพ์ "อัปเดตเกม" (หรือคล้ายกัน) — ไม่ต้องขอลิงก์ ให้หาเอง
1. อ่านชีต KruAu (Google Sheet id `1hWyIK-_z5f8mTiIdC3Ch0Elsw5Zr5DwuBKKs6GweGBs`) แท็บ **Media** คอลัมน์ `url`
   ด้วย Google Drive connector (`read_file_content`)
2. เลือกแถวที่ url เป็น `claude.ai/artifact/<รหัส>` (หรือ `claude.ai/public/artifacts/<รหัส>`) ที่ **ยังไม่มี** ใน `games.json`
   ถ้าผู้ใช้แปะลิงก์มาในแชทด้วย ให้รวมลิงก์เหล่านั้นด้วย
3. ดึงเกมด้วยเครื่องมือ Artifact: `list` scope `files` ดูว่ามีกี่ไฟล์ → `read` ด้วย `paths` ให้ครบทุกไฟล์ (index.html, kit.js, kit.css …)
   - ตรวจว่าไม่มี `window.claude` (API เฉพาะ claude.ai) ถ้ามี ให้แจ้งผู้ใช้ ห้ามย้ายแบบเงียบ ๆ
4. วางไว้ที่ `games/<ชื่อโฟลเดอร์ภาษาอังกฤษสั้น ๆ>/` ทุกไฟล์ในโฟลเดอร์เดียวกัน (แต่ละเกมมี kit ของตัวเอง ห้ามใช้ร่วมกัน)
5. เพิ่มใน `games.json`: `"<รหัส>": {"folder": "<โฟลเดอร์>", "title": "<ชื่อเกม>"}`
6. เพิ่มการ์ดใน `index.html` (หัวข้อ "เกมทั้งหมด") และแถวในตาราง `README.md`
7. ทดสอบเปิดทุกเกมใหม่ด้วย Playwright (file://) ต้องไม่มี page error
7.5 **ซิงก์เกมเก่าที่ผู้ใช้แก้บน claude.ai ด้วยทุกครั้ง** (ผู้ใช้คาดหวังว่า "อัปเดตเกม" = ทั้งเพิ่มเกมใหม่และอัปเดตเกมเดิม):
   ทุกรหัสใน `games.json` → `Artifact list` scope `files` เทียบขนาดไฟล์ (index.html, kit.js, kit.css, block.* …) กับไฟล์ใน `games/<โฟลเดอร์>/`
   ไฟล์ไหนขนาดต่างหรือมีไฟล์ใหม่ → `read` ไฟล์นั้นมาทับ (ไฟล์ที่ไม่เปลี่ยนไม่ต้องอ่าน ประหยัด) แล้วเช็ค `<title>` ว่าเปลี่ยนไหม ถ้าเปลี่ยนให้แก้ games.json/การ์ด/README ด้วย
   ทดสอบ Playwright เฉพาะเกมที่เปลี่ยน
8. commit + push ขึ้น `main` แล้วบอกผู้ใช้เป็นภาษาไทย: ย้ายเกมใหม่ไหนบ้าง + อัปเดตเกมเดิมกี่เกม และ "รอ 1–3 นาทีแล้วเกมจะเปิดในเว็บ KruAu ได้เอง ไม่ต้องแก้ลิงก์"

ห้ามแก้ชีตของผู้ใช้ ห้ามแก้ repo KruAu (game-Kruau) ในงานนี้ — ไม่ต้องให้ผู้ใช้วางไฟล์โค้ดใหม่

## สื่อการสอน (โฟลเดอร์ `media/`)
- สื่อการสอน (บทเรียนโต้ตอบ ใบความรู้ ใบงาน) อยู่ที่ `media/<ชื่อโฟลเดอร์>/` ลิงก์ `https://tanasakbspc01-byte.github.io/kruau-motion-games/media/<โฟลเดอร์>/`
  ผู้ใช้วางลิงก์นี้ในหลังบ้าน KruAu ได้ตรง ๆ (ไม่ต้องผ่าน games.json และไม่ต้องแก้ repo game-Kruau)
- สื่อใหม่: คัดลอก `kit.js` + `kit.css` จากสื่อเดิมมาไว้ในโฟลเดอร์ใหม่ แล้วเขียน `index.html` ตามแบบสื่อเดิม
  (`<section class="slide">` ต่อกันใน `.stage`, เศษส่วนเขียน `{3/4}` จำนวนคละ `{2 3/4}`, แบบทดสอบ `data-quiz` + `Kit.quizzes`, คัดแยก `data-sorter`, เรียงลำดับ `data-order`)
- kit ย่อสไลด์ให้พอดีจออัตโนมัติ (ปุ่ม 🔍) — หน้าที่ตั้งใจให้เลื่อนอ่าน (เช่น ใบงานสำหรับพิมพ์) ใส่ `data-nofit` ที่ `<section>` • ปุ่มเต็มจอ ถ้าเปิดซ้อนในกรอบที่ห้ามเต็มจอ (iPad) จะเปิดแท็บใหม่ที่หน้าเดิม (`#s=<เลขหน้า>`)
- ทุกสื่อต้องมีปุ่ม ✏️ ปากกาเขียนบนสไลด์ และ 🎥 กล้องมุมจอ/อัดวิดีโอ: คัดลอกบล็อก `<style id="kruau-tools">` และ `<script id="kruau-tools">` จากสื่อเดิม (เช่น `media/wk4-careers/index.html`) ไปวางก่อน `</body>`
- ใบงานพิมพ์ได้ `media/m<ชั้น>-worksheets/` (สร้างจาก /home/claude/ws: `page.html` + `ws<ชั้น>.js`, ลิงก์รายบท `#ch<บท>`) เป็นหน้ากระดาษ A4 ไม่ใช้ kit จึงไม่ต้องมีบล็อก kruau-tools (เช่นเดียวกับ `media/m3-times-sheets/` ใบงานสูตรคูณ และ `media/m3-times-game/` เกมเต็มจอที่ไม่ใช้ kit)
- ชื่อโฟลเดอร์: `m<ชั้น>-...` คณิตศาสตร์, `wk<ชั้น>-...` การงานอาชีพ, `th-read<ขั้น>-...` ภาษาไทยอ่านออกเขียนได้ (ทุกชั้น เสียงอ่านใช้ speechSynthesis th-TH) — เพิ่มการ์ดใน `index.html` หัวข้อ "สื่อการสอน" และแถวใน `README.md`
- ทดสอบด้วย Playwright ที่ขนาด iPad (820×1180, 1180×820) และโน้ตบุ๊ก (1366×768) ต้องไม่มี page error และไม่ล้นแนวนอน
