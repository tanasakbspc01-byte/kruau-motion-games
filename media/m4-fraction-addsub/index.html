➖ลบเศษส่วนที่ตัวส่วนเท่ากัน

🧠 นำตัวเศษมาลบกัน ส่วน ตัวส่วนคงเดิม แล้วทำผลลัพธ์ให้เป็น เศษส่วนอย่างต่ำ (ถ้าทำได้)

ตัวอย่าง: {5/6} − {2/6} = ?

1️⃣ มีอยู่ {5/6} (ระบาย 5 ช่อง)

2️⃣ เอาออก {2/6} (กากบาท 2 ช่อง) เหลือ 3 ช่อง

3️⃣ {5/6} − {2/6} = {5 − 2/6} = {3/6}

4️⃣ ทำเป็นเศษส่วนอย่างต่ำ: {3 ÷ 3/6 ÷ 3} = {1/2}

{5/6} − {2/6} = {1/2}

🔁ตัวส่วนไม่เท่ากัน: ทำให้เท่ากันก่อน

ถ้าตัวส่วนตัวหนึ่ง เป็นพหุคูณ ของอีกตัวหนึ่ง ให้ทำเศษส่วนที่ตัวส่วนน้อยกว่า ให้มี ตัวส่วนเท่ากับตัวส่วนที่มากกว่า แล้วจึงบวก

ตัวอย่าง: {1/2} + {3/8} = ?

1️⃣ 8 เป็นพหุคูณของ 2 (2 × 4 = 8) จึงทำ {1/2} ให้ตัวส่วนเป็น 8

{1 × 4/2 × 4} = {4/8}

2️⃣ ตอนนี้ตัวส่วนเท่ากันแล้ว

3️⃣ {4/8} + {3/8} = {4 + 3/8} = {7/8}

{1/2} + {3/8} = {7/8}

🔁ลบเศษส่วน ตัวส่วนเป็นพหุคูณ

ตัวอย่าง: {5/6} − {1/3} = ?

1️⃣ 6 เป็นพหุคูณของ 3 → {1/3} = {1 × 2/3 × 2} = {2/6}

2️⃣ {5/6} − {2/6} = {5 − 2/6} = {3/6}

3️⃣ ทำเป็นเศษส่วนอย่างต่ำ {3/6} = {1/2}

{5/6} − {1/3} = {1/2}

📌 สรุปขั้นตอน: ① ทำตัวส่วนให้เท่ากัน → ② บวก/ลบตัวเศษ → ③ ทำให้เป็นเศษส่วนอย่างต่ำ (ถ้าได้เศษเกิน จะเขียนเป็นจำนวนคละก็ได้)

🍕บวก ลบ จำนวนคละ

บวก: {1 1/2} + {2 1/4} = ?

วิธีที่ 1 แยกบวก จำนวนนับ + จำนวนนับ, เศษส่วน + เศษส่วน

(1 + 2) + ({1/2} + {1/4}) = 3 + ({2/4} + {1/4}) = 3 + {3/4}

วิธีที่ 2 เปลี่ยนเป็นเศษเกินก่อน

{3/2} + {9/4} = {6/4} + {9/4} = {15/4}

{1 1/2} + {2 1/4} = {3 3/4}

ลบ: {3 1/4} − {1 1/2} = ?

1️⃣ เปลี่ยนเป็นเศษเกิน {3 1/4} = {13/4} และ {1 1/2} = {3/2}

2️⃣ ทำตัวส่วนให้เท่ากัน {3/2} = {6/4}

3️⃣ {13/4} − {6/4} = {7/4} = {1 3/4}

{3 1/4} − {1 1/2} = {1 3/4}

💡 การลบจำนวนคละ ถ้าเศษส่วนตัวตั้งน้อยกว่าตัวลบ (เช่น {1/4} < {1/2}) วิธี เปลี่ยนเป็นเศษเกินก่อน จะง่ายที่สุด

🕵️แสดงวิธีทำโจทย์ปัญหา

🧁 แม่มีแป้ง {3/4} กิโลกรัม ใช้ทำขนมไป {3/8} กิโลกรัม แม่เหลือแป้งกี่กิโลกรัม

🔍 โจทย์ถาม แม่เหลือแป้งกี่กิโลกรัม

📌 โจทย์บอก มีแป้ง {3/4} กก. ใช้ไป {3/8} กก.

🧮 วิธีคิด “เหลือ” ใช้การลบ → ประโยคสัญลักษณ์ {3/4} − {3/8} = ☐

✏️ วิธีทำ {3/4} − {3/8} = {6/8} − {3/8} = {3/8}

✅ ตอบ แม่เหลือแป้ง {3/8} กิโลกรัม

🔁 ตรวจคำตอบ {3/8} + {3/8} = {6/8} = {3/4} ✔️ ตรงกับแป้งที่มีตอนแรก
